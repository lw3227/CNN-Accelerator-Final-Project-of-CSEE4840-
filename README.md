# CNN Accelerator Source Handoff

This `pre` branch is a tightened source handoff for the DE1-SoC CNN
accelerator project. It is intended to support the course `.tar.gz` submission:
source files, project configuration, and compact reference artifacts are kept;
generated Quartus/Platform Designer output, logs, local feedback data, and git
history are not part of the archive.
