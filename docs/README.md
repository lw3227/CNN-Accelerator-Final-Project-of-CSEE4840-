# Source Handoff Documentation

This directory contains the documentation needed to reproduce the tightened
`pre` branch source handoff.

Start with:

- [REPRODUCIBILITY_AND_DATA_DEPENDENCIES.md](REPRODUCIBILITY_AND_DATA_DEPENDENCIES.md)

The `pre` branch is intended to remain small and source-oriented. It should not
contain generated Quartus databases, generated Platform Designer HDL,
programming files, local web feedback samples, logs, or git history in the
course `.tar.gz` archive.
