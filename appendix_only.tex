\section{Web-To-Board Runtime Listings}

This appendix lists the source files directly used by the implemented
web-to-board demonstration path. It focuses on the Python host flow, the HPS C
commands executed on the DE1-SoC, and the Verilog/SystemVerilog boundary that
accepts MMIO traffic and starts the accelerator. Lower-level datapath modules,
testbenches, generated Quartus output, generated Platform Designer output,
model-export utilities, MATLAB reference scripts, debug-only tools, image
samples, and git history are kept in the machine-readable archive when needed
but are not repeated in this printed appendix.

\subsection{Web And Host Python Runtime}

\codedlisting{Flask Web Entry Point}{Defines the web routes, service construction, image upload endpoint, and JSON response path.}{code/web_demo/app.py}

\codedlisting{Web Demo Configuration}{Loads board SSH settings, CSR base address, model paths, labels, and fabric-clock configuration.}{code/web_demo/config.py}

\codedlisting{CPU-vs-FPGA Comparison Flow}{Coordinates preprocessing, CPU scoring, board CPU reference execution, FPGA execution, and result formatting.}{code/gesture_runtime/demo_compare.py}

\codedlisting{FPGA Board Service}{Uses SSH/SCP to load the model when needed, copy an exported case to the board, run HPS tools, and parse key-value output.}{code/gesture_runtime/fpga_service.py}

\codedlisting{SSH Transport}{Implements the command execution and directory transfer layer used by the board service.}{code/gesture_runtime/ssh_transport.py}

\codedlisting{Board Transport Interface}{Defines the abstract transport contract shared by SSH and other possible board transports.}{code/gesture_runtime/board_transport.py}

\codedlisting{Inference Case Export}{Writes a preprocessed image into the hardware-aligned case directory consumed by the HPS tools.}{code/gesture_runtime/case_export.py}

\codedlisting{Image Preprocessing}{Converts uploaded image bytes into the 64-by-64 INT8 input tensor and preview image used by the demo.}{code/gesture_runtime/preprocess.py}

\codedlisting{Preprocess Mode Selection}{Chooses the preprocessing branch used by auto mode based on CPU-side scoring.}{code/gesture_runtime/preprocess_selection.py}

\codedlisting{INT8 Quantization Helpers}{Contains the small quantization helpers used by preprocessing and export.}{code/gesture_runtime/quantization.py}

\codedlisting{Host CPU Classifier}{Runs the TFLite CPU model on the host side for comparison and preprocessing selection.}{code/gesture_runtime/cpu_inference.py}

\subsection{HPS Board C Runtime}

\codedlisting{MMIO Register ABI}{Defines the software-visible register numbers, bit fields, control flags, and default scratchpad layout.}{code/include/cnn_mmio_regs.h}

\codedlisting{HPS MMIO Helper API}{Declares the shared C structs and helper functions used by all board-side MMIO commands.}{code/include/cnn_mmio_host.h}

\codedlisting{Common MMIO Implementation}{Maps /dev/mem, writes preload/image words, starts model load or inference, polls status, and reads profile counters.}{code/tools/cnn_mmio_host.c}

\codedlisting{Status Probe Command}{Reads STATUS, PREDICT, IF_ERROR, and profile registers for health checks before web requests.}{code/tools/hps_mmio_status.c}

\codedlisting{Model Load Command}{Loads the preload bundle into the scratchpad and triggers CONTROL[0] model replay.}{code/tools/hps_mmio_load_model.c}

\codedlisting{FPGA Prediction Command}{Writes one exported image case, triggers CONTROL[1] inference, waits for predict_done, and prints web-readable key-value output.}{code/tools/hps_mmio_predict.c}

\codedlisting{Board CPU Baseline}{Runs the same exported case on the HPS CPU baseline so the web demo can compare CPU and FPGA results.}{code/tools/hps_cpu_reference.c}

\subsection{FPGA Board Boundary And Accelerator Top}

\codedlisting{DE1-SoC Board Wrapper}{Connects the generated HPS system, board pins, clocks/resets, and seven-segment debug display.}{code/de1_soc/soc_system_top.sv}

\codedlisting{Avalon-MM MMIO Wrapper}{Implements the scratchpad, register file, replay FSM, status/profile readback, and stream bridge into the accelerator.}{code/input/RTL/interface/cnn_mmio_interface.v}

\codedlisting{Accelerator Top}{Integrates model-load, CNN layer sequencing, SRAM datapath, FC classifier, argmax, and profiling outputs.}{code/input/RTL/system_top.v}

\codedlisting{Network-Level FSM}{Controls the high-level model-load and inference schedule across convolution, FC, and argmax phases.}{code/input/RTL/fsm/top_fsm.v}

\codedlisting{Layer Runner FSM}{Sequences per-layer configuration, weights, input data, output writes, and completion for the CNN layers.}{code/input/RTL/fsm/layer_runner_fsm.v}

\subsection{Submission Package Notes}

The \texttt{.tar.gz} submission should contain only the source files needed to
rebuild and run the design flow. It should exclude generated or bulky outputs
such as \texttt{.git}, Quartus \texttt{db}, \texttt{incremental\_db},
\texttt{output\_files}, Platform Designer generated handoff/synthesis
directories, waveform/debug dumps, collected web feedback samples, and other
generated data products.
