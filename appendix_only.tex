\section{Web-To-Board Runtime Listings}

This appendix lists the source files directly used by the implemented
web-to-board demonstration path. It includes the Python host flow, the HPS C
commands executed on the DE1-SoC, and the synthesizable Verilog/SystemVerilog
hardware used by the FPGA accelerator, including the lower-level SRAM,
convolution, quantization, pooling, and fully connected datapath modules.
Testbenches, generated Quartus output, generated Platform Designer output,
model-export utilities, MATLAB reference scripts, debug-only tools, image
samples, and git history are kept out of this printed appendix.

\subsection{Web And Host Python Runtime}

\codedlisting{Host CPU Classifier}{Runs the TFLite CPU model on the host side for comparison and preprocessing selection.}{code/gesture_runtime/cpu_inference.py}

\subsection{Submission Package Notes}

The \texttt{.tar.gz} submission should contain only the source files needed to
rebuild and run the design flow. It should exclude generated or bulky outputs
such as \texttt{.git}, Quartus \texttt{db}, \texttt{incremental\_db},
\texttt{output\_files}, Platform Designer generated handoff/synthesis
directories, waveform/debug dumps, collected web feedback samples, and other
generated data products.
